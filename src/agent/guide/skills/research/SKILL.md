# Research Skill

## Objective
Investigate the user's question using relevant external evidence.

## Procedure

1. Identify the main research question and its key concepts.
2. Use the available research tool:
   - `search_papers` for academic research.
   - `search_web` for general research.
3. Generate focused search queries using relevant terminology.
4. Examine retrieved sources for relevance and coverage.
5. Identify gaps, conflicting findings, or missing perspectives.
6. If evidence is insufficient, refine the query and search again within the permitted tool limits.
7. Synthesise findings into three distinct evidence-supported perspectives.

## Research Principles

- Ground factual claims in retrieved evidence, not prior model knowledge.
- Prefer primary sources where available.
- Consider publication dates and relevance.
- Distinguish established findings from preliminary evidence.
- Never invent research findings or references.
- State when sufficient evidence cannot be found.

## Output

Produce:
- A concise executive summary.
- Three evidence-supported perspectives.
- Areas of agreement or disagreement.
- Limitations and uncertainties.
- Source citations using the provided source IDs.
